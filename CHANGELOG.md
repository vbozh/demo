### Features

New user-visible capabilities shipped in this sprint.

- **Context window and tokens display for Claude models** ([AIR-5487](https://youtrack.jetbrains.com/issue/AIR-5487))  
  Shows the context window size and token usage for Claude models in the UI.

- **Fast Mode support for Claude Opus via Anthropic API Billing** ([AIR-4630](https://youtrack.jetbrains.com/issue/AIR-4630))  
  Enables Fast Mode for Claude Opus when using an Anthropic API key.

- **Support Claude xhigh effort level (Fable, Opus, Sonnet 5)** ([AIR-6205](https://youtrack.jetbrains.com/issue/AIR-6205))  
  Adds the `xhigh` reasoning effort level for supported Claude model tiers.

- **Add support for Gemini 3.6 Flash** ([AIR-6444](https://youtrack.jetbrains.com/issue/AIR-6444))  
  Integrates Google's Gemini 3.6 Flash as an available agent backend.

- **Proposed diff view in Editor tab** ([AIR-5476](https://youtrack.jetbrains.com/issue/AIR-5476))  
  Users can now view agent-proposed file changes as a diff directly in the editor tab.

- **Open in Web context actions for Cloud tasks** ([AIR-6080](https://youtrack.jetbrains.com/issue/AIR-6080))  
  Adds context menu actions to open Cloud tasks in the browser.

- **AI Quota widget in settings popup** ([AIR-5846](https://youtrack.jetbrains.com/issue/AIR-5846))  
  Displays remaining AI usage quota directly in the settings popup.

- **Environment variable interpolation in `.mcp.json`** ([AIR-6583](https://youtrack.jetbrains.com/issue/AIR-6583))  
  MCP server configurations now support `${ENV_VAR}` syntax for credentials and dynamic values.

### Improvements

Enhancements to existing functionality and user experience.

- **UX for preventing machine from sleeping during active tasks** ([AIR-5191](https://youtrack.jetbrains.com/issue/AIR-5191))  
  The system now prevents sleep mode while an agent task is actively running.

- **Codex agent mode now shows generated code output** ([AIR-5287](https://youtrack.jetbrains.com/issue/AIR-5287))  
  Code generated by Codex in agent mode is now visible in the chat output panel.

- **Fast Mode no longer locks when a Codex chat session starts** ([AIR-5613](https://youtrack.jetbrains.com/issue/AIR-5613))  
  Fixed a state issue where initiating a Codex chat session would permanently lock Fast Mode.

- **`acp.json` shown as non-existing and empty on first open** ([AIR-6124](https://youtrack.jetbrains.com/issue/AIR-6124))  
  The file now opens correctly with its existing content rather than appearing blank.

- **Chat file mentions show stale change count when file has no pending changes** ([AIR-6160](https://youtrack.jetbrains.com/issue/AIR-6160))  
  File mention badges in chat now reflect the accurate, current change count.

- **License texts updated on onboarding and login screens** ([AIR-6217](https://youtrack.jetbrains.com/issue/AIR-6217))  
  Onboarding and login screens now display current license text.
