# Changelog

## Sprint 262.43 — June 2026

This sprint delivers two new features, two visual improvements, and seventeen bug fixes — including a show-stopper that prevented tasks and changes from loading after an update, and a startup crash on certain configurations.

### Features

- **Fast Mode support for Claude Opus 4.6 (API Billing)** ([AIR-4630](https://youtrack.jetbrains.com/issue/AIR-4630))
  Air now supports Fast Mode when using Claude Opus 4.6 via the Anthropic Console API. Fast Mode can be enabled by admins for Teams and Enterprise organizations, and is also available to users on Claude subscription plans via extra usage allowance.

- **Empty drafts are automatically removed** ([AIR-4083](https://youtrack.jetbrains.com/issue/AIR-4083))
  Task drafts that the user has cleared of all text are no longer kept. Empty drafts are now discarded automatically, keeping the task list clean.

### Improvements

- **[Windows] Air icon alignment in the main toolbar** ([AIR-5608](https://youtrack.jetbrains.com/issue/AIR-5608))
  The Air icon in the main toolbar was misaligned on Windows. It is now correctly positioned.

- **[Windows] Duplicate progress spinner during Apply Locally** ([AIR-5609](https://youtrack.jetbrains.com/issue/AIR-5609))
  Two progress spinners were shown simultaneously while an Apply Locally operation was in progress on Windows. Only a single spinner is now displayed.

### Fixes

- **Tasks and changes not loading after update to 262.34** ([AIR-5640](https://youtrack.jetbrains.com/issue/AIR-5640))
  A show-stopper regression in 262.34 caused the Tasks view and the Changes tool to fail to load entirely. Both views now load correctly after the update.

- **Air fails to start on certain configurations** ([AIR-5645](https://youtrack.jetbrains.com/issue/AIR-5645))
  A null-pointer error in the render loop initialization (`RenderLoop.stopAndJoin`) prevented Air from starting on some setups. The startup sequence is now guarded against this condition.

- **Chat messages invisible until the task is stopped** ([AIR-5583](https://youtrack.jetbrains.com/issue/AIR-5583))
  Chat messages produced during a running task were not visible in the chat panel until the task stopped. Messages are now displayed in real time as the task runs.

- **MCP servers list appears empty when servers are available** ([AIR-5561](https://youtrack.jetbrains.com/issue/AIR-5561))
  The MCP servers panel showed an empty list even when MCP servers were active in the current session. The list now correctly reflects available servers.

- **Excessive warnings: selected permission mode not in available modes** ([AIR-5661](https://youtrack.jetbrains.com/issue/AIR-5661))
  A flood of warnings — `Selected mode SelectedPermissionMode(id=) is not in available modes` — was logged whenever no matching permission mode was found. The warning is now suppressed for this expected state.

- **Table rendering and scroll behavior in Chat output** ([AIR-5045](https://youtrack.jetbrains.com/issue/AIR-5045))
  Tables in chat responses rendered with broken layout and incorrect scrolling behavior. Table UI and scroll handling in the chat output area have been fixed.

- **Junie approval view shows no content** ([AIR-4794](https://youtrack.jetbrains.com/issue/AIR-4794))
  The Junie approval panel rendered an empty view, making it impossible for users to review what Junie was about to do before approving. The panel now displays its content as expected.

- **Thinking level switcher missing from the UI** ([AIR-5606](https://youtrack.jetbrains.com/issue/AIR-5606))
  The control for selecting the agent thinking level disappeared from the interface after a recent update. It has been restored.

- **Uncommitted changes lost when using "Implement" in Docker agent** ([AIR-5538](https://youtrack.jetbrains.com/issue/AIR-5538))
  Selecting "Implement" in a Docker-based task discarded any uncommitted local changes without warning. Uncommitted changes are now preserved when the implementation starts.

- **Uncommitted changes lost when using "Implement" in Worktree agent** ([AIR-5484](https://youtrack.jetbrains.com/issue/AIR-5484))
  The same data-loss issue as AIR-5538 affected Worktree-based tasks. Uncommitted changes are now correctly carried over when switching to "Implement" in a Worktree agent.

- **Commits list not shown after implementing a plan in Worktree** ([AIR-5240](https://youtrack.jetbrains.com/issue/AIR-5240))
  After a plan was implemented inside a Worktree agent, the Changes tool showed an empty commits list. The commits list now populates correctly after plan implementation.

- **Can't open a file linked in a markdown plan** ([AIR-5449](https://youtrack.jetbrains.com/issue/AIR-5449))
  Clicking on a file path mentioned in a markdown plan file generated by the agent did not open the file. File links in agent-generated plans are now navigable.

- **Commit message input missing in the Changes tool Diff view** ([AIR-5101](https://youtrack.jetbrains.com/issue/AIR-5101))
  The text field for entering a commit message was absent from the Diff view in the Changes tool. The input is now present and functional.

- **Edit and Revert buttons disappear when resizing the Diff view** ([AIR-5319](https://youtrack.jetbrains.com/issue/AIR-5319))
  Resizing the Diff view caused the Edit and Revert buttons in the file list to disappear. The buttons now remain visible at any panel size.

- **Chat banners do not span the full panel width** ([AIR-5530](https://youtrack.jetbrains.com/issue/AIR-5530))
  Informational banners in the chat panel did not stretch to fill the available width, resulting in a misaligned layout. Banners now correctly fill the full width of the panel.

- **[Windows] Copy does not work** ([AIR-5558](https://youtrack.jetbrains.com/issue/AIR-5558))
  The copy action was non-functional on Windows, preventing users from copying text or content from within the application. Copy now works as expected on Windows.

- **Tooltip flicker when hovering between items** ([AIR-5008](https://youtrack.jetbrains.com/issue/AIR-5008))
  Rapidly moving the cursor between items with tooltips caused visible flicker as tooltips rapidly appeared and disappeared. Tooltip display is now stable on hover.
